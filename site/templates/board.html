The endpoint

InferHub exposes an OpenAI-compatible /v1/chat/completions API. This site probes that endpoint daily with stream: true. A red cell is a shape miss in that run’s JSON. It is not an uptime check and not a score of your traffic.

The matrix

  • Alias: the short name we send in model.
  • Publisher: the model string InferHub returned (who actually served). The alias and the publisher can differ.
  • Pass / fail: that check only, not a full SDK suite. The sentence under the chip is what happened on the wire this run.
  • Info: recorded; it never fails a cell. Price is info and never ranks.
  • Scores: tool names in the SSE stream, prompt cache on a completion with no tools, and mojibake in answers to a Russian question.
